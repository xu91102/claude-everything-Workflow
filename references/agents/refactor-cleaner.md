# Refactor Cleaner 详细参考

> 该文件供 `agents/refactor-cleaner.md` 按需读取。主 agent 文件只保留高频路由和审查流程，以降低默认 token 成本。

## 推荐工具

- `npx knip`：查找未使用文件、导出、依赖和类型。
- `npx depcheck`：查找未使用 npm 依赖。
- `npx ts-prune`：查找未使用 TypeScript 导出。
- `npx eslint . --report-unused-disable-directives`：查找无效 eslint disable。

## 删除前检查

- [ ] 搜索所有静态引用。
- [ ] 搜索字符串形式的动态引用。
- [ ] 检查是否属于公共 API、配置约定、路由、迁移或生成入口。
- [ ] 查看测试、文档和示例是否仍引用。
- [ ] 明确验证命令。
- [ ] 明确回滚方式。

## 安全删除顺序

1. 未使用导入和局部变量。
2. 未使用私有函数、私有类型和内部工具。
3. 未使用内部导出。
4. 未使用依赖。
5. 未使用文件。
6. 重复实现整合。

每个批次后运行相关验证，不把高风险删除混进低风险批次。

## 删除日志模板

```markdown
# 代码删除日志

## YYYY-MM-DD

### 删除项
- `path`：删除原因、证据、替代实现。

### 验证
- 命令：结果

### 风险与回滚
- 风险：
- 回滚：
```

## 风险提示

不要仅凭工具输出删除以下内容：

- 公共导出和包入口。
- 动态导入、字符串路由、配置约定。
- 数据库迁移和历史脚本。
- 认证、权限、支付、文件上传、安全相关代码。
- 测试夹具、mock、示例、文档生成入口。

# 性能与上下文成本

- 选择能可靠完成任务的最低成本模型；深度架构、复杂分析或研究才升级推理能力。
- 默认 MCP 必须高频通用且明显优于 CLI/API；同时启用少于 10 个 MCP、活跃工具少于 80 个。
- 研究、调试或里程碑完成并准备切换阶段时压缩；依赖近期细节、关键决策未整理或风险未确认时不压缩。
- 压缩保留目标、进度、关键文件/接口/决策、风险、阻塞、下一步和待验证假设；压缩后确认这些信息仍可恢复。
- 多 Agent 的选择以 `rules/common/agent-orchestration.md` 为唯一来源；性能评估只计算额外上下文、工具和回传成本。
- 上下文接近上限时避免启动大规模重构或复杂交互调试，优先完成当前可独立验证的切片并交接。

# 代码规模约束 (CRITICAL)

## 规模目标与硬性限制

| 约束项         | 限制           | 处理要求                         |
| -------------- | -------------- | -------------------------------- |
| 单代码文件行数 | **约 800 行**  | 可略超，明显超出时评估是否拆分   |
| 单测试文件行数 | **≤ 1000 行**  | 必须拆分测试场景                 |
| 单函数/方法    | **≤ 80 行**    | 必须提取子函数                   |
| 函数参数       | **≤ 5 个**     | 必须封装为对象                   |
| 嵌套层级       | **≤ 4 层**     | 必须提前返回或提取函数           |
| 单行长度       | **≤ 120 字符** | 必须换行                         |

## 执行与检查

- 检查范围只限本次编辑的代码文件；文档、设计稿和规则说明不受此约束。
- Claude Code 环境由 `hooks/check-code-size.js` 在编辑后自动检查，无需手动统计行数；Codex 等无 Hook 环境按上表自行对照。
- 非测试代码明显超过 800 行参考值或测试文件超过 1000 行时，评估职责是否应拆分。

# 代码规模约束 (CRITICAL)

## 硬性限制

| 约束项      | 限制           | 违反后果               |
| ----------- | -------------- | ---------------------- |
| 单文件行数  | **≤ 600 行**   | 必须拆分文件           |
| 单函数/方法 | **≤ 80 行**    | 必须提取子函数         |
| 函数参数    | **≤ 5 个**     | 必须封装为对象         |
| 嵌套层级    | **≤ 4 层**     | 必须提前返回或提取函数 |
| 单行长度    | **≤ 120 字符** | 必须换行               |

**超限处理**：文件过长→拆分 | 函数过长→提取 | 参数过多→封装对象 | 嵌套过深→早返回

## 自检清单（每次 Write/Edit 后必须检查）

**写完代码后立即验证，不要等到提交前！**

- [ ] 文件是否超过 600 行？→ 必须拆分为多个文件
- [ ] 是否有函数超过 80 行？→ 必须提取子函数或模块
- [ ] 是否有参数超过 5 个？→ 必须封装为配置对象或使用 builder 模式
- [ ] 嵌套是否超过 4 层？→ 必须提前返回（guard clause）或提取函数
- [ ] 是否有超过 120 字符的行？→ 必须换行或简化表达式

### 验证方式

```bash
# 检查单个文件行数
wc -l src/components/MyComponent.tsx

# 检查所有源文件行数
find . -name '*.ts' -o -name '*.tsx' | xargs wc -l | awk '$1 > 600'
```

**Hook 自动化**：已配置 PreCompact Hook 在上下文压缩前提醒规则，Stop Hook 在会话结束时检查所有文件。

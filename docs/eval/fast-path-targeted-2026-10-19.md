skills/code-review/SKILL.md 明确数值搜索/校正算法重写须独立审查，包括精度边界与算术上下文；单一 float 类型的算法重写也适用，并使用新上下文（fork_turns=none 或宿主等价机制），仅传固定审查包。保留低风险自审及必要独立审查，不降低模型或质量要求。

Fast Path 在定位步骤优先修正出错的类型或分支，并复用未受影响的既有路径；保留此前批量读取独立 Git 状态、定位和必要规则片段的改动。有先后依赖的步骤仍顺序执行，不删除质量检查。

失败轮的阶段归因和本轮整体对照均是观察结果，没有对单条规则做因果消融；原生子代理及其用量单独保留供审计。

Fast Path 路由、按风险选择检查、片段读取和避免重复验证继续保留；没有任务名、数值、答案或新审批流程进入规则。

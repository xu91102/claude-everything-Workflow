# Out-of-Scope Knowledge

Use `.out-of-scope/<concept>.md` only for rejected enhancements, never bugs or already implemented
requests.

One file represents one concept and contains:

- what is out of scope;
- durable strategic or technical reason;
- prior request links.

When a related request arrives, surface the record and ask the maintainer whether the decision still
holds. On confirmation, append the request and close it. On reconsideration, update/delete the record
and resume normal triage. Temporary lack of time is a deferral, not a durable rejection.
